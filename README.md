# ⚡Programa de cálculo de energia
Este projeto em Python tem como objetivo cálcular o consumo médio de eneria de um aparelho eletronico, com base na sua potencia em watts. 
O programa solicita o **nome do aparelho**,**potência em watts** e o **tempo de uso diário em horas**. Em seguida, calcula o consumo mensal e o valor aproximado que o aparelho gastaria de energia. 

## 🐍 Linguagem utilizada

- Python

## 🧮 Fórmula utilizada

O consumo mensal é calculado utilizando a seguinte fórmula:
consumo mensal = (potência × horas de uso diário × 30) / 1000
